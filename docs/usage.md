# Generate documents

Inject `Lle\PdfGeneratorBundle\Generator\PdfGenerator`.

## From a template in database

Give the template code and a list of data sets: **each data set produces a document**, and the documents are
merged into one PDF.

```php
public function invoice(Invoice $invoice, PdfGenerator $pdfGenerator): Response
{
    // HTTP response (the temporary file is deleted after sending)
    return $pdfGenerator->generateResponse('INVOICE', [['invoice' => $invoice, 'customer' => $invoice->getCustomer()]]);
}
```

```php
$path = $pdfGenerator->generatePath('INVOICE', $dataSets);     // path of a temporary PDF file
$merger = $pdfGenerator->generate('INVOICE', $dataSets);       // PdfMerger, see below
$merger->merge('file', '/tmp/invoices.pdf');
```

Without data (`[]` or `[[]]`), a `crudit_report` template is rendered with its test data (or with the sample of its
[data source](data-sources.md)). The admin "Show the PDF" action does that.

## From a resource

Without a template in database, give the type and the resource:

```php
return $pdfGenerator->generateByRessourceResponse(WordToPdfGenerator::getName(), 'invoice.docx', $dataSets);
$merger = $pdfGenerator->generateByRessource(TcpdfGenerator::getName(), MyTcpdfClass::class, $dataSets);
```

## Several templates in one document

A template can chain several resources, each with its type (the first type is used for the resources without
type, and `default_generator` when the template has no type):

```php
return $pdfGenerator->generateByRessourceResponse(
    [TcpdfGenerator::getName(), WordToPdfGenerator::getName()],
    [MyTcpdfClass::class, 'letter.docx'],
    $dataSets,
);
```

```sql
INSERT INTO lle_pdf_model (code, libelle, path, type) VALUES
('REMINDER', 'Reminder', 'letter.docx,App\\Service\\Pdf\\Invitation', 'word_to_pdf,tcpdf');
```

## PdfMerger

`generate()` and `generateByRessource()` return a `Lle\PdfGeneratorBundle\Lib\PdfMerger`:

```php
$merger->merge('download', 'invoice.pdf');  // or 'file', 'browser', 'string'
$pdf = $merger->toTcpdfFpdi();              // TCPDF + FPDI instance, to add content
$pdf->AddPage('P');
$pdf->writeHTML('Hello', true, 0, true, 0);
$pdf->Output('/tmp/file.pdf', 'F');
```

A PdfMerger cannot be signed: see [Sign documents](signature.md).

## Options

Options apply to the next documents generated by the service:

| Option | Type | |
|---|---|---|
| `PdfGenerator::OPTION_EMPTY_NOTFOUND_VALUE` | `word_to_pdf` | `true`: an unknown variable is replaced by an empty text (default: the variable name stays) |
| `CruditReportGenerator::OPTION_GROUPS` | `crudit_report` | Serializer groups of the data (default `['pdfgenerator']`), for templates without data source |

```php
$pdfGenerator->addOption(PdfGenerator::OPTION_EMPTY_NOTFOUND_VALUE, true);
```

## Other criteria

To select the templates by more than their code (a template per tenant, for example):

```php
$pdfGenerator->setCriteria(['tenant' => $tenant]);
```
